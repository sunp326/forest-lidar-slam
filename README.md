## 📊 Dataset

### 自采数据集：喜鹊梁林场
- **采集地点**：河北省张家口市喜鹊梁林场
- **采集设备**：Livox MID-360 激光雷达 + IMU
- **场景特征**：针阔混交林，郁闭度 0.7~0.8，林下 GNSS 拒止
- **下载链接**：[百度网盘](https://pan.baidu.com/s/13X7PlluKVNIDeyO99Fneyw?pwd=1111)（提取码：1111）

### 公开数据集
- [BotanicGarden Dataset](https://github.com/robot-pesg/BotanicGarden)

## 🛠️ Environment & Dependencies
- Ubuntu 20.04
- ROS Noetic
- PCL, Eigen, GTSAM
- Livox ROS Driver
